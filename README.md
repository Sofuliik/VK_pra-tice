Учебный проект, разработанный в рамках летней практики VK. Представляет собой серверное приложение с REST API и взаимодействием с базой данных.

Возможности
- управление данными через REST API;
- работа с сущностями и базой данных;
- выполнение операций создания, чтения, изменения и удаления данных.
